Проект "Бронирование переговорных комнат".

Планирование и создание репозитория

1. Обдумать предметную область и выделить основные сущности. 
2. Конкретизировать доменные модели влоть до типов полей и составить связи между ними.
3. Выделить правила бизнес логики.
4. Развернуть Postgres базу в докер контейнере.
5. Установить task (автоматизация задач) и goose (инструмент миграции).
6. Написать миграционные скрипты.
7. Проверить миграции и откаты.
8. Проверить созданные объекты в БД (вставка, чтение, удаление, в том числе полностью БД).
